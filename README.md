# 이거어때유

**이거어때유**는 대전 시민을 위한 음식점 정보 제공 서비스로 사용자 편의성과 맞춤형 경험을 제공하며, 지역 상권 활성화를 도모하는 맛집 추천 서비스입니다.

## 🧭 프로젝트 목표

- 사용자가 원하는 **지역**과 **메뉴**를 빠르고 정확하게 검색하고 리뷰를 확인할 수 있도록 합니다.
- **실시간 인기 검색어**, **개인화된 추천**, **위치 기반 정보 제공**을 통해 사용자 맞춤 경험을 제공합니다.
- **정확한 리뷰와 메뉴 정보**로 사용자 의사결정을 돕습니다.
- **지역 상권 추천**을 통해 소상공인의 매출 증대 및 지역 경제 활성화를 지원합니다.

---

## ✨ 주요 기능

### 🔍 사용자 편의성 증대
- 직관적인 UI로 메뉴 및 지역 선택
- 빠른 맛집 정보 및 리뷰 제공

### 🎯 맞춤형 추천 서비스
- Redis 기반 **실시간 검색량** 반영 인기 키워드 제공
- **키워드 즐겨찾기 기능**으로 개인화된 경험 제공
- 사용자의 **위치 기반** 가까운 맛집 정보 제공

### ✅ 사용자 의사결정 도움
- **정확한 리뷰 및 메뉴 정보 제공**
- **실시간 인기 메뉴/리뷰 기반** 빠른 선택 가능

### 🧠 개인화된 경험 제공
- **즐겨찾기** 및 **검색 기록 기반** 추천
- **트렌드 기반** 실시간 메뉴 랭킹 제공

### 🏪 지역 상권 활성화
- **지역 맛집 노출**로 소상공인 매출 증가
- **상권 분석 및 전략 수립** 지원
- **카카오 지도 API**를 활용한 사용자-상점 연결 강화

|------|-------------------------|
| **김승진 (팀장)** | 리뷰 CRUD, 서버 구축, 크롤링 데이터 저장 및 전송 로직 |
